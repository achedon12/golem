# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be patient, be respectful. Harassment, insults and personal attacks are not
tolerated, in issues, pull requests or anywhere the project is represented.

Report unacceptable behaviour privately through
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or to the maintainer, [@achedon12](https://github.com/achedon12). Every report is reviewed and kept
confidential.
